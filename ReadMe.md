This repo currently just contains a single Juypter notebook with programs for testing aspects of the Welter game.  The game is described at the top of the notebook.  There are a number of technical functions related to the analysis of the game, coming from John Conway's book On Numbers And Games. I am looking at this as part of a research collaboration with two other math professors. Running a cell towards the end of the Juypter notebook, you can actually play a simple console version of the game against an optimal computer player - have fun!
